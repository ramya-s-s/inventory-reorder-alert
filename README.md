# Inventory Reorder Alert System

A Python script that reads inventory data from a CSV file, identifies items that need restocking, classifies their priority, generates a restock report, exports it to CSV, and prints a simulated email alert.

## Features
- Read inventory from CSV
- Detect low-stock items
- Critical and Low priority classification
- Suggested reorder quantity
- Export restock report to CSV
- Simulated email alert
- Basic error handling
